# Vakwen Domain Language

Vakwen models portfolio facts and evidence-backed market research. This glossary records the domain terms whose distinctions are required for consistent contracts and acceptance evidence.

## Taiwan Research Acceptance

**Reference Subject**:
A versioned real or fixture-backed subject selected to exercise one or more Taiwan Stock Research acceptance paths. It may be an Issuer, Security, Listing, source artifact, or synthetic portfolio context.
_Avoid_: Reference company, test ticker

**Acceptance Gate**:
One of the three independently satisfied boundaries for specification handoff, implementation conformance, or rollout readiness.
_Avoid_: Release stage, test phase

**Acceptance Case**:
A stable, traceable statement of preconditions, execution path, expected evidence, prohibited outcomes, and pass/fail oracle for one or more normative requirements.
_Avoid_: Test scenario, checklist item

**Acceptance Manifest**:
An immutable record of the exact code, contracts, policies, fixtures, environment, results, reviews, and waivers used to decide an Acceptance Gate.
_Avoid_: Test report, latest results

**Golden Path**:
A complete, decision-grade operating-company research run that exercises all mandatory evidence paths for one Listing Venue.
_Avoid_: Happy path
